# Day 2

# 学习跨境电商核心指标

预计：

4小时

---

建立你的指标字典

---

# GMV

Gross Merchandise Value

公式：

GMV = Orders \times AOV

含义：

成交总额

---

# AOV

Average Order Value

公式：

AOV = \frac{Revenue}{Orders}

---

# Conversion Rate

转化率

公式：

CR = \frac{Orders}{Visitors}

---

# CAC

获客成本

公式：

CAC = \frac{Marketing\ Cost}{New\ Customers}

---

# ROAS

广告回报率

公式：

ROAS = \frac{Revenue}{Ad\ Spend}

---

# LTV

用户生命周期价值

公式：

LTV = Average\ Order\ Value \times Purchase\ Frequency \times Customer\ Lifespan

---

# 输出

Ecommerce_Metrics.md

内容包括：

| 指标   | 含义   | 高好还是低好 |
| ---- | ---- | ------ |
| GMV  | 成交额  | 高      |
| CAC  | 获客成本 | 低      |
| ROAS | 广告回报 | 高      |
| LTV  | 用户价值 | 高      |
