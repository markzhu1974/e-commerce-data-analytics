# Day 7

# 数据质量检查

预计：

5小时

---

企业项目第一件事：

检查数据质量。

---

# 缺失值

例如：

```sql
SELECT COUNT(*)
FROM orders
WHERE delivered_timestamp IS NULL;
```

---

# 重复值

```sql
SELECT customer_id,
COUNT(*)
FROM customers
GROUP BY customer_id
HAVING COUNT(*) > 1;
```

---

# 异常值

例如：

价格异常：

```sql
SELECT *
FROM order_items
WHERE price > 10000;
```

---
