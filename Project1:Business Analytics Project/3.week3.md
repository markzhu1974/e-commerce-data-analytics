# Day 1

# 销售分析（Sales Analytics）

预计：

4小时

---

## 业务问题1

总GMV是多少？

SQL：

```sql
SELECT
SUM(payment_value) AS GMV
FROM payments;
```

---

## 业务问题2

总订单数

```sql
SELECT
COUNT(DISTINCT order_id)
FROM orders;
```

---

## 业务问题3

客单价（AOV）

公式：

AOV=\frac{GMV}{Orders}

SQL：

```sql
SELECT
SUM(payment_value)
/
COUNT(DISTINCT order_id)
AS AOV
FROM payments;
```

---

## 业务问题4

月度GMV趋势

企业最喜欢问。

```sql
SELECT
DATE_TRUNC('month',
purchase_timestamp) month,

SUM(payment_value)
FROM orders o
JOIN payments p
ON o.order_id=p.order_id

GROUP BY 1
ORDER BY 1;
```
