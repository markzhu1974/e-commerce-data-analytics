# 最终项目在招聘经理眼中的形态

很多MORSE学生的简历：

```text
MSc MORSE

Statistics

Econometrics

Coursework
```

面试官看不出实际业务能力。

而完成这8周项目后，你的定位会变成：

> MSc MORSE + SQL + Python + Power BI + 跨境电商经营分析项目

对于中国跨境电商企业的数据分析、商业分析、BI分析岗位而言，这种组合的竞争力会明显高于只有课程和理论背景、缺少项目实践展示的候选人。

如果后续还有时间，我建议在这个项目完成后，再追加一个 **“跨境广告投放ROI优化+A/B Test项目”** 和一个 **“供应链需求预测项目”**，这样会形成“经营分析 + 增长分析 + 预测分析”三件套作品集，对安克、SHEIN、Temu等企业会更有吸引力。
